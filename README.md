# Meme Dost
A chat friend that replies only with Indian-style memes and GIFs.

- Frontend: `index.html` (static, hosted on GitHub Pages)
- Backend: Supabase Edge Function `chat` (already deployed), which calls GIPHY

## Publish
Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
Your site appears at https://YOUR-USERNAME.github.io/REPO-NAME/ in about a minute.
